⚙️ How it works — the n8n pipeline

1Patient calls / chatsPhone or website widget
→
2Webhookn8n receives the call or message
→
3AI AgentOpenAI agent answers, books, qualifies
→
4Google SheetsCall + booking logged automatically
→
5Gmail summaryOwner gets a summary by email

The production workflow is in n8n/aria-voice-receptionist.json — import it into n8n, connect your own OpenAI, Google Sheets and Gmail credentials, and point your phone system / website at the webhook. The Python server on this page is the demo version of the same idea: same API shape, same log — but with a rule-based agent instead of a live LLM, so it runs anywhere with zero setup.

Pricing shown here is sample data for the fictional BrightSmile Dental clinic. In production, prices come from the business's own price list.
